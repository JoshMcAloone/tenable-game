# Question Set Curation Guidelines

Quality Checklist:
- Clear scope: players should reasonably guess 10 items.
- Avoid ambiguous phrasing; include source context when niche.
- Keep answer length concise (<35 chars typical).
- Balance difficulty: 3 easy, 4 medium, 3 hard (suggestion).
- Avoid culturally narrow or sensitive topics.

Testing:
- Dry-run with at least 2 people.
- Confirm no duplicate synonyms (merge or clarify).

Versioning:
- Increment file set or maintain separate JSON per batch.

Out-of-Scope (MVP): scoring weights, categories.
